Telegram Bot 通知设置

配置后，当签到任务执行失败时，系统将通过 Telegram Bot 向您发送通知提醒。

使用提示
  • 创建机器人：在 Telegram 中联系 @BotFather，发送 /newbot 按照指引创建通知机器人，获取 Bot Token。
  • 获取 Chat ID：
    • 个人私聊通知：先在 Telegram 中找到您的机器人点击 Start，然后可通过 @userinfobot 获取您自己的用户 ID。
    • 群组通知：将机器人拉入目标群组，Chat ID 通常为负数（例如 -1001234567890）。
  • API 基础地址：默认为 https://api.telegram.org。如需反代，管理员须先在 webapp 和 scheduler 服务的 NOTIFICATION_TRUSTED_ORIGINS 环境变量中允许该 HTTPS 基础地址；仅允许公网目标。
开启后，当定时计划任务、批量执行或手动执行签到失败时，将自动向指定的 Telegram 账号或群组推送失败告警。
由 @BotFather 提供的 HTTP API Token。
接收通知消息的个人 Telegram ID 或群组 ID。
默认为 https://api.telegram.org，反代须在服务器端白名单内，仅支持无路径的 HTTPS 基础地址，不支持私网地址、重定向或环境代理。
